# Gestor de Finanzas Personales | Hackaton Frontend 2026

Aplicación web de una sola página (**SPA**) desarrollada para el desafío del Hackaton Frontend 2026, orientada al control diario, visualización y gestión de ingresos y gastos personales.

## 🚀 Características Principales

- **Formulario de Registro:** Permite registrar movimientos indicando descripción, monto, tipo (ingreso/gasto) y categoría (Sueldo, Comida, Transporte, Servicios, Ocio, Otros).
- **Panel de Balance Global:** Tarjetas superiores que actualizan en tiempo real los _Ingresos Totales_, _Gastos Totales_ y el _Balance Neto_.
- **Historial Interactivo:** Tabla dinámica con diferenciación visual de colores (verde para ingresos, rojo para gastos) y sistema de confirmación previa al eliminar registros.
- **Resumen por Categorías:** Agrupación automática de los montos movilizados en cada categoría.
- **Persistencia de Datos (`localStorage`):** Almacenamiento local en el navegador para preservar la información al recargar la página.

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Maquetación estructurada)
- **Tailwind CSS** (Diseño responsivo y estilizado vía CDN)
- **Vanilla JavaScript** (Lógica de programación basada en **Programación Orientada a Objetos** con Clases y Módulos ES6)
